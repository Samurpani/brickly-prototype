# Flow: Launch Package

**[MVP·concierge]** — sold as the Launch activation package (€15k, v19 pricing); produced by humans behind the Studio Wizard. Source: `source/bricly-flow-launch-package.md` (5-phase ideal flow where Studio generates everything).

## What it is

The "make this project market-ready" bundle for a development going on sale: brand direction, hero renders + render set, brochure, microsite/landing page, unit collateral, lead form — delivered through Bricly so every asset lands in the Asset library and every lead lands in the pipeline.

## v1 flow (concierge behind the product)

1. **Brief** — owner runs the **Studio Wizard** (Brief type: *Launch Package*): development, services, buyer context, style direction, timeline → submitted brief appears in Studio → Projects as **Requested**.
2. **Consultation** — brand consultation call (the deep flow prototyped in `Bricly_Brand_Consultation_Prototype.html`); direction locked with the member.
3. **Production** — concierge team (founder + render/brand contractor) produces assets with external tools; status → **In production** with progress %. Every brief and output format documented — this is v1.1 training data.
4. **Delivery** — assets land in **Asset library** (per development, "Requested by / Delivered" register) and attach to the development's Media tab; status → **Delivered**. Hosted lead form (capture Tier 1) goes live pointing at the pipeline.
5. **Launch** — units on sale, leads flowing, Present Mode data (photos, hotspots, floor plans, finish options) collected as a by-product for v1.1.

SLA expectations set per-brief in the wizard's Timeline step. Personalisation sub-briefs (custom renders for a specific buyer) follow the same path with a ~24h SLA — see `buyer-customisation.md`.

## Deferred from the ideal flow

Automated brand-system generation, render pipelines, brochure/microsite generation, CAD-to-JSON ingestion — **[v1.1]** (this *is* v1.1's build scope). Phase-gated client approval UI inside Studio → [v1.1]; v1 approvals happen on the consultation calls.
