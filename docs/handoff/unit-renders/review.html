RulesHow the system decides. Read once.

  • Every render has a room. Layout, finish and style are optional. Blank means any.
  • Every render has a scope: one unit, all units of a type, or the whole development.
  • Priority: unit beats type beats development. Exact tag beats any.
  • Several matches in one room become the angles in that room.
  • Option with no render of its own: that room keeps the default image.
  • Present only offers options that have renders. Finishes tab always lists every pack.
  • No renders at all: Renders tab is hidden. No views: Views tab is hidden.
  • Nothing reaches Present until Publish.

Open questionsMy calls. Confirm or change each one.

  1. Chip wording. A room with no Dusk render shows the default image. The chip then says Stone while the card says Dusk package. Keep, or show "Dusk · no render here"?
  2. Layout price. Layouts carry a price in the catalogue. It is not added to the unit price yet. Add it?
  3. Default scope. Upload defaults to all units of the same type. Right default?
  4. Lists per development. Rooms, layouts and styles are set per development. Share them across a developer instead?
  5. Untagged files. A file with no room lands in Media and blocks publish until it has alt text. Block, or park it out of the way?
  6. Approval. Managers request review. Owners publish. Same for renders, or let marketing publish renders alone?
