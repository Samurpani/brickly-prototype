RulesHow the system decides. Read once.

  • A level plan is one drawing. It covers a floor range. Example: Typical floor, floors 2–40.
  • Each outline on the drawing has a label. Bricly reads the label.
  • Match rule: label equals the unit reference. Or label equals the last digits after the floor number. 03 on floor 32 matches AP.3203.
  • No match: unit is flagged Needs placing.
  • Manual choice beats automatic. Reset to automatic removes the manual choice.
  • One outline holds one unit per floor. Taken outline: swap or cancel.
  • Own outline: drawn for one unit. The shared plan does not change.
  • Not on a plan: needs a reason. Unit is left off the floor view.
  • Changes go to the draft. Present updates on Publish.
